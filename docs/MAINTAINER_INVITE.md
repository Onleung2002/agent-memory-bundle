# Co-maintainer Invitation Letter（草稿 v1）

## 用法

- 目標人選：W3C CG 內 independent 個體（無 vendor 利益關係）——候選短名單見下
- 途徑：經對方 GitHub（CG participants 頁有直接連結）開 contact／帖 issue；或者 CG 認識後 email
- **披露尺度（重要）**：只講 mission + 治理，唔講 G-gate 日期、定價、beachhead 策略

## 邀請信（英文，per-recipient 填名）

Subject: Co-maintainer invitation — open conformance effort for portable agent memory

Hi {name},

I'm Isaac Leung — I believe we're both in the W3C AI Agent Memory Interoperability Community Group.

I'm building **MBCP** (Memory Bundle Conformance Profile): an open, vendor-neutral conformance layer for portable AI agent memory — a profile compatible with existing protocol work, an executable test suite, and verifiable-deletion (GDPR Art. 17) evidence tooling. The repository is live with CI: https://github.com/Onleung2002/agent-memory-bundle (private for now — I'll add you as a collaborator on acceptance; it goes public at our first external milestone).

Why you specifically: the project's credibility rests on independent governance, and your profile in the CG — engaged, with no competing vendor interest — is exactly what its GOVERNANCE.md calls for at this stage. I'm deliberately not recruiting from any spec-authoring camp.

Honest commitment estimate: 1–2 hours/month now (reviewing spec changes, voting); more if you ever want it. Rights: co-maintainer vote on every spec/requirement change; no vendor seats; you'd be listed from the first public version.

No obligation at all — happy to have a call or a thread first if you'd like to see how the suite is shaping up.

Best regards,
Isaac Leung
